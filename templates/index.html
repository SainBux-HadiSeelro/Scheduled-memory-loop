How the Memory Spine Works

        
Every time you click Run Digest Beat (or when the scheduled loop runs), the scanner finds all open TODOs and compares them against signatures saved in progress.md. Only NEW TODOs are appended. If nothing changed, it records that no new TODOs exist. The memory survives across restarts solely through the spine file.
